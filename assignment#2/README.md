Thread Store follows the clean black and white look of a fashion retailer: a thin promo bar, a centred logo, a small category menu, a full-width banner, one featured product, product cards and a simple footer. It is a smaller layout with a static banner, eight clothing items and a basic footer.

Open `index.html` in a browser. Click the featured coat (or the first product) to open `product.html`.
Bootstrap CSS loads from the CDN shown in Lecture 10, and the product photos load from Unsplash, so an internet connection is needed. The cart buttons are static for Assignment 2.

## Course material used

- Lectures 3 and 4: HTML pages, links, images, semantic elements, the size select box and the quantity input.
- Lectures 5 and 6: external CSS, colours, fonts, backgrounds, margins, padding and borders.
- Lecture 9: Flexbox for the navigation, menu and banner content.
- Lecture 10: Bootstrap navbar and grid, responsive images and media queries.
